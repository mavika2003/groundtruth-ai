# GroundTruth AI: Retrieval Ablation Study

**Status:** Template. Populate only after running the same 150-case corpus and model configuration across all four modes. Do not present placeholder values as results.

## Research question

Does BM25 fusion and cross-encoder reranking improve grounded-answer quality enough to justify their latency and cost versus dense-only retrieval, while preserving document-level access control?

## Controlled setup

- Corpus: `groundtruth.benchmark.seed`, 30 policy facts plus conflicting and restricted companion documents.
- Query set: 150 synthetic labeled cases generated by `groundtruth.benchmark.cases`.
- Identity: employee JWT, no access to `admin` documents.
- Fixed variables: embedding model and dimensions, chat model, prompt version, top-5 context, database contents, model temperature.
- Modes: dense; BM25; hybrid reciprocal-rank fusion; hybrid plus cross-encoder reranking.
- Run each mode at least three times for latency. Exclude the reranker cold start from steady-state latency, but report cold start separately.

## Interpretation limits

The seed corpus and questions are synthetic and template-derived; they are a reproducible integration benchmark, not an externally valid enterprise evaluation. Citation ID validity only checks that cited IDs were retrieved, not that their passages entail the answer. Exact expected-string containment is a narrow accuracy proxy. Ragas scores are LLM-judged and may vary across runs. Before making resume claims about improvements, add human-reviewed cases from a licensed dataset and report confidence intervals.
